# Issue #867 Windows Electron acceptance

This sample uses original raster art and a procedural audio timing track
generated by `scripts/generate-issue867-sample.cjs`. It contains no third-party
media. The subtitle is original sample dialogue; the generated audio is a
non-verbal timing tone so an owner can replace it with a preferred recording.

## Build and open the sample

From the Issue #867 branch on Windows:

```powershell
pnpm evidence:issue867-fixture
pnpm dev
```

The first command prints a new project folder beneath
`D:\PandaStage-Acceptance\issue867-thm01\`. In Panda Stage, open the generated
`.pandastage` project folder. Each run gets a unique folder and does not
overwrite earlier evidence.

## Visual path

Use the `小芽` character and the `Diagonal dialogue` Shot.

1. **Character settings preview:** open Settings, start Preview, and observe
   the head and face move together from upper-left through neutral to
   lower-right. Set the existing intensity control to 0%, 100%, and 200%; the
   first setting stays still and the latter two scale both axes together.
2. **Shot canvas:** scrub to about 425 ms (upper-left) and 675 ms (lower-right).
   The dialogue begins at 300 ms. Confirm the body stays still and the head
   returns to neutral when the dialogue ends at 2,700 ms.
3. **Product Preview:** pause and seek to the same two times. The head-group
   offsets should match the canvas.
4. **MP4:** export the Shot and inspect frames near 425 ms and 675 ms. Confirm
   the same diagonal endpoints, neutral start/end, aligned face, stationary
   body, subtitle, and dialogue audio.

The exact frame can be a few milliseconds from the listed sample time because
the project is 24 fps. Use the nearest frame before comparing surfaces.
