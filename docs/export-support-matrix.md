## Current formal-export profile

- Output: 1920×1080 at 24 fps.
- Shot count: 1–256; every Shot needs a visible image background.
- Camera modes: static, speaker-focus. Character compositions: whole-image, composite.
- Frozen media: at most 512 used assets, 64 MiB per asset, and 256 MiB total. Only media actually used by the Project is frozen.
- Windows formal MP4 target and same-directory staging paths are limited to 259 characters; longer paths are blocked before preparation.

These are code protection limits, not measured performance promises. The matrix lists the narrow capability evidence for each content path; it does not imply that every Project within a limit will complete on every device.
