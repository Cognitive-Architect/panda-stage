## Day 25 实际结果

- `createPresetEvents` 为纯函数：唯一 id（可注入 `options.createId`）、整数 ms（四舍五入）、
  1920×1080 逻辑坐标、离屏入场；输出通过 `TimelineEventSchema`。
- `validatePresetApplication` 为单一拒绝闸门：背景层、重复 id、越界（中文「超出镜头时长」）、
  不透明度越界 0–1、表情不属于角色均**拒绝 + 中文原因**，绝不静默截断（工单红线 4）。
- `actionPresetStore` 桥接：读 `editorProjectStore`/`shotStore`/`selectionStore` →
  `createPresetEvents` → `validatePresetApplication` → 仅当通过才 `applyPresetEvents` +
  `updateProject`，全部历史自动记录（undo/redo 免费）；未选/背景/锁定/非角色直接拒绝，零修订。
- T03 双链收敛：StageRenderer / CanvasStage / StagePreview / ExportRendererApp 统一引用正式
  `src/domain` 的 `Project`/`EvaluatedShot`/`evaluateShotAtTime`；正式 evaluator 处理全部 7 类事件，
  StagePreview / Export 调用时传入 `project`；`probe-project.ts` 改为正式 `startMs/endMs` 形状。
- T01 迁移回填：v1/v2 经 `addBackgroundIdentity`、v3/v4 经 `?? []` 回填 `timelineEvents`，且
  `ShotBaseShape.timelineEvents` 加 `.default([])`，旧项目打开后严格 `ProjectDataSchema` 通过。
- R6：`evaluateShotAtTime` 遇到失效 `expressionId` 回退到 layer 基 expression，**不抛错**，渲染不崩。
