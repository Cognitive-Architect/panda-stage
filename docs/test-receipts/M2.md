## Day 20 实际结果

- `ShotService` 集中处理创建、复制、重命名、时长更新、移除和移动。
- 复制镜头为 Shot、Layer、AudioClip、Dialogue 和 TimelineEvent
  生成全局唯一的新 ID，并重映射 `dialogue.audioClipId` 与
  `timelineEvent.layerId`；素材、角色、声音和字幕样式等外部引用保持复用。
- 拖拽调用 `ShotStore.move()`，最终写回 `Project.shots`，所有模型变更进入
  `EditorProjectStore` 的 dirty/revision/autosave 流程。
- `currentShotId` 仅存在于 Renderer 会话 store，不写入 Project 或
  `project.json`。
- 移除当前镜头后优先选择原索引上的下一个镜头，其次选择前一个；移除最后
  一个镜头后选择为 `null`，界面明确引导创建新镜头。
- `durationMs` 在 schema 和 service 两层要求为有限整数且不少于 500ms，
  并禁止缩短到已有对白、音频或时间事件结束点之前。空输入映射为 `NaN`，
  与小数、`NaN` 和 499ms 一并被拒绝。
- 项目总时长由纯 selector 对全部 `shot.durationMs` 求和。
- 缩略图是明确占位组件；未实现画布、时间轴、转场或批量编辑。
