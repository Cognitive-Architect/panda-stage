## 各票实际交付与已知缺口

### #1448 R01 多条具名刚性骨链

- 交付：`CharacterArmChainEntrySchema`（`id/name/kind/chain`）+ 可选 `armChains`；旧 `armChain`
  无损映射为默认链（`DEFAULT_ARM_CHAIN_ID`，UUID 而非字面量，因 `IdSchema` 为 uuid）；
  `saveCharacterArmChain/rename/delete` 按 `chainId` 工作；导入计划重映射链内 `partId`；
  Inspector 链选择与新建/重命名/删除；画布拖柄与装配按选中链隔离。
- 缺口：共享祖先的多链协同移交 #1455/#1456；无运行时 IK 轨（票面允许）。

### #1449 R04 现成分件动作局部修改

- 交付：`CharacterActionCopyService`（`duplicateCharacterActionForInstance` / `revert` /
  实例编辑上下文 / 动作本地时间写键）；`LayeredCharacterActionSchema` 新增可选
  `originActionId` + `instanceScope`；IK/姿态在实例副本段内写入副本动作轨（播放真正消费的数据）；
  UI 每段「复制为可编辑副本 / 恢复共享动作」；整图 baked 动作明确拒绝。
- 缺口：动作段起点非整数帧时，写入键按动作帧网格取整（沿用既有捕获语义）；
  副本段内的轨道面板裁剪/重定时仍作用于图层 clip；删除动作事件后副本定义不自动 GC；
  画布拖柄不叠加 `partPivotOffsets` 校准。
- 集成补充：删除动作时若不仍被实例副本引用则拒绝（`scanCharacterActionReferences` 增加
  `character-action-origin`）。

### #1450 F01a 跨帧稳定节点身份

- 交付：`nodeIdentityAliases`（按 `frame:<ordinal>` / `sym:<defId>` 容器 + nodeId 持久化）；
  既有 `addr:`/`sym:`/`node:` 证据规则不变，别名仅在无证据时生效（`alias:`）；纯函数
  建立/解除/枚举歧义；`LayerService` 两条命令（一次一条撤销）；内部时间轴条提供
  「建立节点关联 / 解除关联」；歧义节点保持 `readonly-identity`。
- 缺口：重捕获导致 nodeId 变化时别名悬挂（安全忽略）；同一部件在一帧唯一、另一帧重复时
  不能并入 `addr:` 身份；存在轨道/挂接引用时解除关联被硬拒绝（不静默改写轨道）。

### #1451 F01b 复杂仿射与斜切

- 交付：`M = R(rotation)·K(skewX)·S(scaleX,scaleY)` 精确分解（TRS 安全矩阵不输出 `skewXDeg`，
  旧数据字节不变）；`isAffineMatrixDecomposable`；斜切线性插值；连续键行列式变号视为
  近奇异风险（`readonly-affine-unsafe`，新键拒绝，既有数据沿用历史插值）；Inspector「斜切 °」。
- 缺口：未用真实 XFL 样本校对 AN 的斜切符号/单位；不猜测整圈转数（票面要求）。

### #1452 F09 合法原生 Graphic 定义

- 交付：`source.origin: 'native'`（外部来源仍强制 `basename/sha256/renderTargetId` 与逐帧
  `assetId/sha256`，原生定义禁止携带这些伪造字段）；原生节点 `authored: 'native'`，真实矢量
  区域存放在既有 `flaGraphicSharedShapeOverrides`，无空图占位；`NativeGraphicDefinitionService`
  从选中子节点创建、独立副本、增删/重排/替换节点、引用与资源删除保护；库面板标识与操作；
  Stage/Preview/Export 走同一 `evaluateFlaGraphicVisual`。
- 缺口：替换节点内容仅 domain 层（无选择器 UI）；新增节点 UI 只支持「复制选中节点」；
  `offset` 必须非负，故原生定义 `anchor` 为 `{0,0}`、`canvas` 取内容包围盒（枢轴为中心）。

### #1453 F09 内部曝光与原生帧编辑

- 交付：曝光单元复用既有 Definition 帧契约——每个播放帧序号即曝光单元，held 单元带
  `holdFromOrdinal` 且无 layers，`resolveFlaGraphicStructureFrame` 解析为权威帧；空白关键帧、
  复制帧、延长/缩短曝光、层新增/删除/前后移、解组/组合；原生节点跨多帧保持 `node:<id>` 身份；
  移除内容清理实例/共享覆盖与别名，轨道保留为惰性；源导入定义拒绝全部操作并保持字节不变
  （冻结 baseline 夹具）。
- 缺口：结构树/画布节点编辑仍固定在权威帧 0（播放与其他帧的 domain 编辑正确，但无 UI 进入
  帧 1+ 直接编辑）；「插入空白关键帧」不移动后续序号（原地置空或追加）；缩短不能删除权威帧；
  组合/解组只做静态渲染测试。

### #1454 F07 镜头原生覆盖遮罩

- 交付：图层级 `maskTargets`（单向真值，反向派生）；`coverage-mask` 单一解析器；正式求值产出
  `EvaluatedLayer.coverageMask`；Coverage 路径复用既有矢量命令转换；Stage/编辑画布用同一
  Konva `clipFunc` 裁剪且命中一致；遮罩层不入画、编辑态可选（半透明）；失效目标/循环局部降级；
  清除恢复；Inspector「设为遮罩 / 选择被遮罩图层 / 解除遮罩」；镜头缩略图隐藏遮罩层并失效指纹。
- 缺口：只做 coverage，无 alpha/luminance、软边、任意嵌套（嵌套被拒）；非 FLA 图层按图层
  包围盒覆盖；缩略图不执行裁剪；未做真实 Electron 像素级对照。

### #1455 R02 通用骨树与 FK

- 交付：可选 `bones`（`parentBoneId`/`partId`/`restLocal`/`length`/角限），树校验（无环、单根、
  部件唯一绑定）；`character-bone` 动画目标与键轨（沿用五属性与既有 key/easing/undo 机制）；
  `character-bone-pose.ts` 纯 FK（父先子后、rest 时 delta 为单位阵）；部件最终矩阵 =
  `delta ∘ 既有部件姿态`（只一次组合，不双重变换）；保护脸嘴/头动；挂接读取最终矩阵；
  `CharacterBoneService` + Inspector 骨骼面板（建/删/重绑/rest/角限/记录姿态）。
- 缺口：无画布骨骼手柄；时间轴不渲染骨骼轨（仅数值面板写键，默认线性）；角限只是元数据，
  求值不 clamp；`CharacterBodyPoseService`/步态/模板仍按部件局部姿态计算，与骨骼绑定混用时
  仅在检查器提示；骨架 IK 遇到骨骼绑定部件时明确报错。

### #1456 R03 世界末端锁定

- 交付：图层级 `endEffectorLocks`（`space: 'character' | 'stage'`、`target`、可选
  `footRotationDeg`/`weight`/`activeRange`）；`character-end-effector-lock.ts` 纯解算（复用
  `solveRigidArm`，保持骨长与角限，根骨不参与）；正式求值后处理并暴露 `endEffectorResiduals`；
  优先级：叶深优先、先解者拥有共享祖先、后解者报 `shared-ancestor` 残差；残差阈值 0.75 舞台单位；
  Inspector 锁定列表与残差提示；「记录姿态」走锁定解算，一次手势一条撤销。
- 缺口：无画布骨盆拖拽手势（用数值姿态控件）；`weight` 未在 UI 暴露；仅 2–3 段链；
  共享祖先多端点只做文档化降级，无物理/全身配平。

### #1457 F02 原生 Shape Tween

- 交付：`shapeMorph.ts` 纯几何（线段/二次精确升三次、面积配对、de Casteljau 补点、闭合方向与
  起点对齐、缺失轮廓退化、缓存 `prepareShapeMorphPair`）；`flaShapeTween.ts` 作者轨（两端姿态、
  起止时间、缓动、稳定目标键）存于结构可选字段；求值在既有内部时间轴路径上替换该区域几何，
  端点精确；`LayerService` 创建/更新/删除；Inspector 时长/缓动/删除入口。
- 缺口：不插值填充/描边样式（必须一致，否则拒绝）；只支持定义级（非实例级）补间；
  跨端点顶点覆盖层可能显示旧几何（重新解析后正常）；未做真实 Electron 导出对照。

### #1458 F02 形状提示点与多轮廓

- 交付：提示点在既有对齐之前生效（分割/旋转起点/弧段配对）；交叉/重复/越界提示给
  typed failure 并保持原几何；外轮廓 + 直接孔洞的多轮廓配对（孔洞方向相反、不翻面、孔洞不越出
  外轮廓）；样式边界文档化并拒绝不一致；提示增删改经 `LayerService` + store，一次一条撤销；
  Inspector 提示面板（锚点选择方式）。
- 缺口：无画布点击/拖拽放提示与手柄（用锚点选择）；姿态改动导致段数变化时提示失效（拒绝写入，
  已持久化的失效提示局部降级）；多轮廓仍是面积/包含启发式，非 Adobe 私有规则。
