# N1-02｜从空项目完成一次不插代码的制作

> 来源：N1～N7 分阶段执行计划 v1.1。状态字段只表示本路线图任务定义，不替代实时 GitHub / MasterMind 状态；实际执行前仍需核对当时仓库、依赖和维护者授权。

## 所属阶段与边界

**阶段目标：**不再重复逐功能演示，而是从空项目完成 10～15 秒双人对白项目，交付真实摩擦账本。[R §5]

**进入条件：**采用 Day29 后已接受的可用版本；维护者授权本次采样。**离开条件：**当前承诺范围内的编辑、分镜头预览、保存重开成立，严重阻塞没有被隐藏。

**明确不做：**本阶段不要求 MP4、不要求一次连续播放所有镜头、不临时加入状态系统或动作系统；采样过程中不改代码。未来缺少的表达能力要记录，但不伪装成已承诺功能的故障。

## 本卡执行内容

**类型 / 风险：**真人生产采样 / 中。**前置：**N1-01。

**本次成果：**第一段真实项目和制作记录，证明能否通过正式界面做出来。

| 序 | 任务 | 责任区域 | 实施细节 |
|---:|---|---|---|
| 1 | 新建并搭镜头 | 正式项目 / 角色 / 镜头 / 画布 | 从空项目建立 2 角色、2 镜头；不复制已完成工程 |
| 2 | 录入并安排对白 | 字幕工作区 / 时间轴 | 至少 6 行；实际使用手动拖入或自动加入，记录选择原因与阻碍 |
| 3 | 绑定真实配音 | 当前属性 / AudioClip | 至少 4 段；按需要裁剪或恢复可用长度；不假造音频时长 |
| 4 | 查看实际结果 | 当前单镜头预览 | 两个镜头分别完整播放；检查说话人、字幕、声音、简单嘴型；不声称整项目连播 |
| 5 | 保存与恢复工作 | 正式保存 / 打开路径 | 保存、关闭项目、重开，再查看镜头内容与预览；不得手改文件补救 |

**UI/UX：**观察画布是否可见、列表是否连续、时间编辑是否好抓、配音是否容易找到。主理人不知道下一步时记录求助，不把执行者口头导航省略掉。

**自动验证（V-DOC）：**辅助计时/文件清单/录屏时间戳可自动整理；只检查记录缺项，不自动把缺项填 PASS。项目数量可通过已支持的只读检查辅助，但不能代替真人路径。

**人工验收：**依次完成上表全部正式 UI 步骤；记录分镜头预览及重开结果；每次卡住写下原本想做什么、实际做法、能否继续。无法完成就保留受阻工程与复现，不删剧情制造成功。

**交付与完成：**项目、操作记录、主动时间/等待时间、求助与摩擦列表；结果允许 PASS 或 FAIL，真实受阻的采样也算采样任务完成，但阶段仍可能未通过。

**止损：**作品丢失、异常覆盖、跨项目污染时立即停止并保留副本；不在本轮边演示边修。**后继：**N1-03。
