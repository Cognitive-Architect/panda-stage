Panda Stage — FLA V1 parser runtime notice
============================================

This notice covers the bounded parser closure used by Panda Stage FLA V1.
It is copied into packaged Windows builds by electron-builder.yml under
resources/licenses. It is not a normal editor UI surface.

Parser provenance
-----------------

Upstream repository: https://github.com/lifeart/fla-viewer
Pinned upstream commit: 048000ccab67469980b8dedd1fc2b65a02d2b164
Upstream entry point: FLAParser.parse
Panda source adapter: src/renderer/fla-import/fla-viewer-adapter.ts

The shipped parser-core closure is exactly these 12 upstream files:

  adpcm-decoder.ts
  binary-fla-parser.ts
  binary-fla-structure.ts
  binary-instance-decoder.ts
  binary-shape-decoder.ts
  binary-timeline-decoder.ts
  edge-decoder.ts
  fla-parser.ts
  flv-parser.ts
  ole2-reader.ts
  path-utils.ts
  types.ts

The local copies are byte-for-byte equal to the pinned upstream files after
normalizing repository line endings and removing one leading Panda build-
compatibility comment (`// @ts-nocheck ...`) from each file. No parser logic,
runtime behavior, or upstream file list is locally modified. The preamble is
the only permitted local modification and is reviewable in the PR.

The closure is bundled into the built Electron renderer by the `flaParser`
Vite entry (`fla-parser.html`). It is not a dependency on the upstream viewer,
player, exporter, muxer, or web application. The only external parser runtime
imports are the exact packages listed below.

License and residual-risk status
--------------------------------

The pinned upstream package and README declare ISC intent, but the pinned
upstream tree has no authoritative LICENSE, COPYING, or NOTICE file. The
status is therefore:

  LICENSE_INTENT_ONLY

The intended identity is ISC; this notice does not manufacture an upstream
license grant. This status and the decision to proceed are the maintainer's
explicit Issue #250 decision:

  https://github.com/Cognitive-Architect/panda-stage/issues/250

Direct parser runtime dependencies
----------------------------------

  jszip@3.10.1       (MIT OR GPL-3.0-or-later)
  pako@1.0.11        (MIT AND Zlib)

JSZip's package artifact offers a choice of MIT or GPLv3. Panda Stage uses the
MIT option for this bounded closure. The authoritative package license file is
`node_modules/jszip/LICENSE.markdown` and the pinned source is linked above.
Pako's package README identifies MIT for its wrapper and Zlib for the
`lib/zlib` subtree; the standard Zlib notice is reproduced below.
